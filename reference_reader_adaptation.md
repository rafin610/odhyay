# Reference Reader Adaptation

The inspected course reader uses a compact document-control strip above the page canvas. Its practical sequence is **zoom out → zoom percentage/status → zoom in → previous page → direct page-number field → total page count → next page → fullscreen**. The page canvas stays centered and uncluttered, while course-level context is kept outside the document area.

ODHYAY will adapt this interaction model rather than copy its visual treatment. The redesigned reader will preserve ODHYAY’s quiet editorial typography, warm-paper/Night reading appearance, global colour-mode switch, reading-progress persistence, and continuous fullscreen scroll. It will add a direct page input with safe bounds, a compact zoom readout, grouped previous/next controls, and a desktop/phone adaptive toolbar. On phones, essential navigation remains thumb-reachable while secondary controls move into an expandable, accessible utility row.
